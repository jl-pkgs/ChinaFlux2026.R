# 2 模型起跑

## 2.1 模型参数

- `植被参数`：

  + `clumping index`：输入
  + `lai`：输入
  + `气孔导度与光合参数`：率定

- `土壤参数`：
  + 主要输入土壤质地的类型，其他通过率定获取。
  + 土壤水力属性数据：Dai2019 或者GlobalSoilMap。

## 2.2 Hourly Met气象驱动

- `Rs`     : 入射短波，W m-2
- `Rln_in` : 入射长波，W m-2
- `Tair`   : 冠层之上空气温度，deg
- `RH`     : 冠层之上相对湿度，%
- `Prcp`   : 降水，mm h-1，（最好在冠层之上，否则受冠层截留蒸发影响）
- `Uz`     : 冠层之上风速，m s-1

> 注意Tair, RH, Uz最好在同一高度

## 2.3 状态变量

- `Ta`: 冠层之下

- `RH`: 冠层之下

- `TS`: 土壤温度

- `SM`: 土壤湿度
