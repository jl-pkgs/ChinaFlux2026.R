摘要：橡胶林是海南岛的主要人工植被类型之一，作为我国热区重要的森林生态系统，在区域碳水循环中扮演重要角色，观测橡胶林的碳水通量对于评估橡胶林碳水平衡以及能量交换至关重要。儋州橡胶林自 2009 年 11 月起开展了近地层通量观测（包括涡度相关系统和梯度观测系统），至今已积累 12年的通量和气候观测数据。本数据集整理了 2010 年至 2018 年的海南儋州橡胶林通量和常规气象数据，包括了半小时、日、月及年尺度的生态系统 $\mathrm { C O } _ { 2 }$ 净交换通量、生态系统呼吸、总初级生产力、潜热通量、显热通量、水汽通量、空气温度、空气湿度、水汽压、风速、风向、大气压、总辐射、净辐射、光合有效辐射、土壤温度、土壤含水量和降水量等指标。本数据集可为橡胶林生态系统评价和经济社会可持续发展规划提供更多的依据和参考。

# 引 言

橡胶树（Hevea brasiliensis）原产巴西亚马逊河流域，是比较典型的热带雨林树种， 也是热带地区重要的经济林木，自20世纪初我国引进橡胶树开始，经过多年发展已形成产业化种植，截至 2019年全球橡胶种植面积达 $1 . 5 \times 1 0 ^ { 7 } \mathrm { h m } ^ { 2 [ 1 ] }$ 。

自 20 世纪 50 年代起，为冲破西方的橡胶封锁，我国开始大力发展橡胶事业，并成功突破植胶禁区，在热带北缘高纬度地区成功种植天然橡胶树。20 世纪 80 年代开始，海南的民营橡胶在国有橡胶的带动下迅速发展，迄今为止，海南橡胶种植面积约占海南岛植被总量的四分之一，橡胶种植已成为海南的主要人工植被类型[2-3]，也是我国热带地区重要的生态系统之一。橡胶林作为人工经济林利于经济发展，然而不少学者认为橡胶林对生态环境造成负面影响，如水土养份流失、土壤退化、生物多样性降低[4-6]，而另一些学者认为橡胶林具有水土保持、水源涵养、固定二氧化碳、维持生物多样性和土壤肥力等生态功能[7]，且在11种不同的土地利用类型中碳储量排名前四位，具有一定的固碳作用[8-9]。近年来橡胶价格下跌，对以价格为导向的种植业而言，也已有不少管理改善措施，如“近自然管理”模式可明显改良土壤并促进养分积累，提升土壤质量[10]，通过间作植物改善橡胶林的土壤物理化学和水文特性，促进养分的累积，从而达到固碳减排的目的[11-12]。

我国以论文形式发表的碳水通量观测数据主要集中在草甸、森林、湿地、灌丛和农田系统中[13-23]，针对橡胶林的仅有西双版纳一个观测数据集[24]。橡胶林具有森林生态系统的物质循环特征，在区域碳循环中扮演着重要的角色，然而作为人工林，橡胶林也受到周期性经营活动的影响，使其循环特征与传统森林之间有一定的区别，且研究相对其他森林较为滞后。本数据集整理了 2010 年 1 月到 2018 年 11 月的海南岛儋州受到周期性经营活动的橡胶林通量数据和常规气象数据，形成了半小时、日、月和年尺度 4 类文件，以期为进一步准确评估橡胶林碳汇能力提供科学依据，更可为我国参与国际碳贸易和气候变化谈判提供支持。

# 数据采集和处理方法

# 1.1 样地描述

研究区域位于海南岛西北部的儋州市中国热带农业科学院试验农场第三试验区 $( 1 0 9 ^ { \circ } 2 8 ^ { \prime } 3 0 ^ { \prime \prime }$ E、$1 9 ^ { \circ } 3 2 ^ { \prime } 4 7 ^ { \prime \prime } \mathrm { N } )$ ，平均海拔 $1 4 4 . 0 \mathrm { m }$ 。气候为热带海岛季风气候，水热条件充沛，年均日照时数达 2000.0小时以上；分明显的旱雨两季，5 至 10 月为雨季，11 月至翌年 4 月为旱季，年均降水量约 1607.0$\mathrm { m m }$ ；年均温 21.5 至 $2 8 . 5 ^ { \circ } \mathrm { C }$ ；相对湿度在 $8 0 . 0 \%$ 以上。

研究站点为海南儋州热带农业生态系统国家野外科学观测研究站。儋州橡胶林通量塔为高通量观测铁塔，搭载有通量和梯度系统，林地为2001年种植的成龄橡胶树人工林，群落高度约为 $1 8 . 0 \mathrm { m }$ ，面积为 $3 . 4 \mathrm { h m } ^ { 2 }$ ，坡度小于 $2 5 . 0 ^ { \circ }$ ，常年平均风速为 $2 . 0 { \sim } 2 . 5 \mathrm { m }$ ，土壤为花岗岩风化而成的砖红壤， 多为沙质粘壤土。橡胶林植物群落结构单一，分为橡胶林乔木层和林下草本层。林下人工间种鹤望兰（Strelitzia reginae），其余为当年生草本植物，主要有弓果黍（Cyrtococcum patens），羽脉山麻杆（Alchornea rugosa），露籽草（Ottochloa nodosa），竹节草（Chrysopogon aciculatus），杯苋（Cyathulaprostrata），含羞草（Mimosa pudica）等。橡胶树种植的行间距为 $3 . 0 \mathrm { m }$ ，列间距为 $7 . 0 \mathrm { m }$ ，5–12 月为割胶期，12月 $-$ 翌年2月林间有压青、施肥、除杂草等林间管理措施。观测铁塔高 $5 0 . 0 \mathrm { m }$ ，开路涡度相关系统安装在 $2 5 . 0 \mathrm { m }$ 高处。

# 1.3 数据加工、处理方法与过程

三维风速、温度及其脉动， $\mathrm { C O } _ { 2 }$ 和水汽通量原通过开路涡度相关系统（OPEC）观测，风向风速、空气温湿度、光合有效辐射、辐射、土壤温湿度、土壤热通量通过气象梯度系统观测。原始数据均由系统软件 Loggernet 记录和实时计算，涡度相关系统输出 $1 0 \mathrm { H z }$ 实时数据，梯度观测系统输出 10 分钟、30分钟和每日数据。数据的处理流程见图1。

通量计算：综合中国通量网和 Li-COR 公司数据处理方法，通过二次开发设计的 EdiRe 软件，针对 $1 0 ~ \mathrm { H z }$ 原始数据，参照吴志祥等人[25]前期处理橡胶林通量数据的方法，进行野点去除，两次坐标旋转，显热通量超声虚温校正、WPL 校正、频率响应校正及夜间通量矫正。橡胶林生态系统的冠层为闭合冠层，部分 $\mathrm { C O } _ { 2 }$ 会被储存在冠层之下和观测高度以下的大气中，因此生态系统 $\mathrm { C O } _ { 2 }$ 净交换通量（NEE）计算公式为： ${ \mathrm { N E E } } = { \mathrm { F c } } + { \mathrm { F s } }$ ，其中Fc为垂直涡流通量，Fs为碳储量通量。

质量控制：经过处理得到 $3 0 \mathrm { { m i n } }$ 数据文件后，需要进行质量控制，主要是对处理计算后的观测资料一系列检查和筛选过程。对于通量数据的检查过程，主要是进行湍流稳态测试、大气湍流谱分析、大气湍流统计特性分析、能量闭合分析和通量足迹源区分析。通量数据的筛选过程为，采用平均值检验法确定了摩擦风速阈值为 $\mathrm { { \tt u } } ^ { * } { = } 0 . 1 2 \ \mathrm { m } { \cdot } \mathrm { s } ^ { - 1 }$ ，对于 $\mathrm { u } ^ { * }$ 低于临界阈值的数据进行剔除；由于通量塔为开路涡度检测系统，考虑到降雨的影响，对有降雨发生时段的通量数据进行了剔除；采用三倍标准差法，以 15 日为界限，计算 $\mathbf { x } \pm 3 \sigma$ （其中 $\mathrm { ~ \bf ~ X ~ } , ~ \sigma$ 分别为 15 日数据的平均值和标准差），剔除在阈值之外的异常值；对明显超过其正常范围的数据进行剔除；对持续一段时间数值相等的数据进行剔除。气候数据的筛选过程为剔除以下异常值：空气温度和土壤温度小于 $0 . 0 ^ { \circ } \mathrm { C }$ ；湿度小于 $0 . 0 \%$ 或大于 $1 0 0 . 0 ~ \%$ ；风速大于 $2 0 . 0 \ \mathrm { m { \cdot s ^ { - 1 } } }$ ；总辐射小于 $0 . 0 ~ \mathrm { W } { \cdot } \mathrm { m } ^ { - 2 }$ 或大于 $2 0 0 0 . 0 ~ \mathrm { W } \mathrm { \cdot m } ^ { - 2 }$ ；净辐射小于-150.0$\mathrm { W } { \cdot } \mathrm { m } ^ { - 2 }$ 或大于 $1 5 0 0 . 0 \mathrm { W } { \cdot } \mathrm { m } ^ { - 2 }$ ；光合有效辐射小于 $0 . 0 \mu \mathrm { m o l } { \cdot } \mathrm { m } ^ { - 2 } { \cdot } \mathrm { s } ^ { - 1 }$ 或大于 $2 5 0 0 . 0 \mu \mathrm { m o l } { \cdot } \mathrm { m } ^ { - 2 } { \cdot } \mathrm { s } ^ { - 1 } .$ 。

数据插补：参考 Wutzler 等人[26]改进后的边际分布采样法，该方法综合了查表法和平均日变化法，即在填补涡度通量和气象数据时，考虑到了通量与气象变量的协同变化以及通量的时间自相关性。首先基于查表法在一定时间窗口内优先利用气温、辐射和饱和水汽压茬三个环境要素约束插补后的数据（变异范围为 $2 . 5 ^ { \circ } \mathrm { C }$ 、 $5 0 . 0 \mathrm { W } { \cdot } \mathrm { m } ^ { - 2 }$ 和 $0 . 5 \mathrm { k P a }$ ）；其次如果只有辐射数据，插补的时间窗口缩小到前后14日；最后如果环境要素缺失，进一步扩大时间窗口，重复以上步骤直到全部缺失数据插补。缺失值大于14日的未插补。

$\mathrm { C O } _ { 2 }$ 通量数据的拆分和融合：通过夜间观测数据进行通量拆分，参考 Reichstein 等人[27]的方法。

首先，估算整个数据集的生态系统呼吸温度敏感性 $\mathrm { E } _ { 0 }$ ；其次，将全年夜间有效数据按照4 日的时间窗口分组，拟合得到每个时段的参考温度下的生态系统呼吸 $\mathrm { R } _ { \mathrm { r e f } }$ ，没有拟合的时间段利用线性插补的方法；最后利用 $\mathrm { E } _ { 0 }$ 和 $\mathrm { R } _ { \mathrm { r e f } }$ 将净生态系统碳交换量划分为总初级生产力和生态系统呼吸。

# 数据质量控制和评估

涡度相关系统数据质量的一个重要依据是系统能量平衡状况，即直接观测的湍流能量（ $_ \mathrm { H s + L E }$ ）与常规气象观测所得的有效能量（Rn-G-S）之间的平衡，其中 Hs 和 LE 分别为显热通量和潜热通量，Rn为净辐射，G为土壤热通量，S 为冠层热储量。不同时间尺度的橡胶林生态系统能量平衡比率均在 $7 3 . 0 ~ \%$ 以上[28-29]，全年闭合度处于中等水平，数据质量符合研究要求。根据前期通量足迹与源区分布的研究[30]，在生长季节不稳定的大气条件下，橡胶林在迎风方向上 $8 0 \%$ 的通量贡献区为 $0 . 0 \sim$ $7 5 8 . 0 \mathrm { m }$ ，在垂直于迎风方向上的范围为- $- 2 5 1 . 0 { \sim } 2 5 1 . 0 \ \mathrm { m }$ ，在生长季节稳定大气条件下，在迎风方向上 $8 0 . 0 \%$ 的通量贡献区为 $0 . 0 { \sim } 1 8 5 8 . 0 \mathrm { m }$ ，垂直于迎风方向范围为- $. 5 3 4 . 0 { \sim } 5 3 4 \mathrm { m }$ 。整体来说橡胶林通量站点的风浪区长度可满足要求，观测到的数据质量可靠，可做后续分析。

湍流数据质量评价参考吴志祥[31]等人的方法，进行湍流稳定性测试和湍流整体特征检验，获得稳态测试指数（SST）和总体湍流特征指数（ITC），根据数据范围分类表（表5）进行初步数据质量分级判断，之后采用 3 级分布法，将 SST 和 ITC 综合筛选，从而控制最终数据等级分布（表 6），其中 0和1表示可用于通量分析，2视为无效数据。

# 4 数据价值

本数据集为长时间序列的橡胶林碳水通量观测数据，由于地处海南岛，受台风影响几率较大，经常性的降水导致数据完整性较低，尤其在 2017 和 2018 年。即便几乎每年都有数据缺失，已有的观测资料也表明橡胶林是一个碳汇（表7）。目前只有泰国、科特迪瓦和中国利用涡度相关技术对单一橡胶林生态系统进行了相关研究，我国开展研究的地点主要在云南西双版纳和海南。由于天然橡胶市场胶价低迷，当前植胶企业和胶农收入锐减，对橡胶林碳汇进行动态监测，研究橡胶林的土壤和水文动态，提高橡胶园的增汇减排技术的同时进行生态扶贫与生态补偿，对促进区域经济发展有重要意义。作为热带橡胶人工林生态系统碳水能量循环的背景资料，本数据集可对未来橡胶林可持续发展及碳汇贸易提供基础数据支撑。

# A dataset of carbon and water fluxes and micrometerological elements in Danzhou rubber plantation (2010-2018)

YANG Siqi1, 2, LIU Junyi1, 2, YANG Chuan2, LAN Guoyu1, SONG $\mathbf { B _ { 0 } } \mathbf { 1 } , \mathbf { 2 }$ , WU Zhixiang1, 2

1. Rubber Research Institute, Chinese Academy of Tropical Agricultural Sciences/Danzhou Investigation＆ Experiment Station of Tropical Crops, Ministry of Agriculture and Rural Affairs, Danzhou 571737, China 2. College of Ecology and Environment, Hainan University, Haikou 570228, China;

\*Email: zhixiangwu@catas.cn

Abstract: Rubber plantation is one of the main artificial vegetation types in Hainan Island. As an important forest ecosystem in China’s tropical regions, rubber plantation plays an important role in the regional carbon and water cycle. Measuring the carbon and water fluxes is critical for estimating the carbon and water balance and energy exchange of rubber plantation. Since November 2009, near-surface $\mathrm { C O } _ { 2 }$ and $_ \mathrm { H _ { 2 } O }$ fluxes observation have been carried out in Danzhou rubber plantation, including eddy covariance system and meteorological observation system. Up to now, it has accumulated flux and meteorological observation data for 12 years. This dataset organizes the rubber plantation flux and conventional meteorological data in Danzhou from 2010 to 2018, including net ecosystem productivity, ecosystem respiration, gross ecosystem productivity, latent heat flux, sensible heat flux, evapotranspiration, air temperature, air relative humidity, vapor pressure, wind speed, wind direction, atmospheric pressure, total radiation, net radiation, photosynthetically active radiation, soil temperature, soil water content and precipitation. This dataset can provide basis and reference for ecosystem evaluation and sustainable development planning in economic and social.

Keywords: eddy covariance; flux; carbon-water cycle; meteorological element; rubber plantation
